How ASR Works in this System

The ASR Tool utilizes an end-to-end Sequence-to-Sequence Deep Transformer architecture trained on 680,000 hours of multi-accented speech data:

01

Audio Resampling

Raw acoustic signals are decoded into 16-bit PCM mono waveforms normalized at 16,000 Hz.

02

Log-Mel Spectrogram

Calculates an 80-channel log-magnitude spectrogram over 25ms windows with 10ms hops.

03

Transformer Encoder

Processes spectrogram patches through stacked 1D convolutions and multi-head self-attention.

04

Autoregressive Decoder

Predicts target token sequences, timestamps, and language identities using beam search.

REST API Integration

Integrate automated speech recognition directly into your Python, JavaScript, or mobile apps: 

# 1. Transcribe Audio File (Returns JSON with timestamps)
curl -X POST http://localhost:5000/api/transcribe \
  -F "audio_file=@your_recording.wav" \
  -F "model=base" \
  -F "language=en"

# 2. Spoken Language Detection
curl -X POST http://localhost:5000/api/detect-language \
  -F "audio_file=@your_recording.wav"

# 3. Health & Diagnostic Check
curl http://localhost:5000/api/health
